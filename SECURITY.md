# Security Policy

## Supported Versions

The versions listed below are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 4.x     | :white_check_mark: |
| < 4.0.0 | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

If you discover a security vulnerability in this project, please report it privately:

- **GitHub Private Advisory:** Go to the [Security Advisories](https://github.com/rafisarkar0128/djs-prototype/security/advisories) tab and click **"Report a vulnerability"**.
- Alternatively, you can reach out directly via Discord through the [Support Server](https://discord.gg/E6H9VvBdTk) or contact the maintainer directly.

Please include a detailed description of the issue, steps or code to reproduce it, and its potential security impact. Vulnerabilities will be addressed as promptly as possible.
